# 프로젝트 지도 (PROJECT MAP) — 비개발자용 작업 분해 대시보드

> 이 문서는 기획자·PM 등 **비개발자 독자**를 위한 한 장짜리 지도입니다. 프로젝트가 무엇을
> 하는지, 작업이 어떻게 나뉘어 있는지, **지금 무엇을 하고 있는지**를 코드를 읽지 않고도
> 파악할 수 있게 만든 자료입니다.
>
> ⚠️ 이 문서는 **파생본(요약·번역본)이지 원본이 아닙니다.** 원본은 `docs/product-specs/`
> (무엇을 만드는가)와 `docs/exec-plans/active/` (어떻게 나누는가)입니다. 내용이 서로 다르면
> 항상 원본이 맞고, 이 지도는 다시 갱신됩니다. 생성·갱신은 `brief` 스킬이 담당합니다.

**마지막 갱신 / Last synced:** _(아직 채워지지 않음 — `brief` 스킬 실행 시 날짜·출처 커밋 기록)_

## 🗂️ 작업 분해 / Work Breakdown

상태 표시: ✅ 완료 · 🔄 진행 중 · ⏳ 예정 · ⛔ 막힘

```
프로젝트
├─ 1. [단계 이름]                              🔄  ← 큰 묶음 (예: "사용자 관리")
│   ├─ 1.1 [기능 이름]                         ✅      무엇을/왜 한 줄 설명
│   ├─ 1.2 [기능 이름]                         🔄      무엇을/왜 한 줄 설명
│   └─ 1.3 [기능 이름]                         ⏳      무엇을/왜 한 줄 설명
└─ 2. [단계 이름]                              ⏳
    └─ 2.1 [기능 이름]                         ⏳      무엇을/왜 한 줄 설명
```

각 노드의 원본 문서:

| 노드 | 무엇을 하나 (비개발 언어) | 상태 | 원본 문서 |
|------|---------------------------|------|-----------|
| 1.1  | _…_ | ✅ | [spec/plan 링크] |
| 1.2  | _…_ | 🔄 | [spec/plan 링크] |
