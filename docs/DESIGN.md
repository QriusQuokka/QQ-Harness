# Design

> Product/system design notes. **Frame only** — fill in as real design decisions are made.

## How to use this doc
Capture durable design decisions here so they're reachable by the agent. For each decision
record: the problem, the options considered, the choice, and **why** (the trade-off). Link
to the exec-plan that produced it.
