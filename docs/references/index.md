# References

External knowledge pulled **in-repo** so it is reachable at runtime. If the agent can't
retrieve it from the repository, it effectively doesn't exist — so vendor the important
parts here rather than relying on external links alone.

## Convention
Prefer `*-llms.txt` (LLM-oriented condensed reference) files, named by source:
- `design-system-reference-llms.txt`
- `<tool>-llms.txt` (e.g. a package manager, a framework)
